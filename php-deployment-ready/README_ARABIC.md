# دليل تشغيل وتثبيت التطبيق بنظام PHP & MySQL (مع معالج التثبيت التلقائي مثل CMS)

---

## 🌟 ميزة التثبيت التلقائي الذكي (CMS Auto-Installer):
الآن، **لا تحتاج إلى الدخول إلى phpMyAdmin أو تعديل أي كود يدوياً!**
بمجرد رفع الملفات إلى استضافتك والدخول إلى موقعك لأول مرة، سيفتح لك **معالج التثبيت التلقائي الذكي (`install.php`)** مثل أنظمة ووردبريس وجملة:
1. **فحص الخادم**: التأكد من توافق إصدار PHP وامتدادات PDO.
2. **ربط قاعدة البيانات**: إدخال اسم قاعدة البيانات والمستخدم واختبار الاتصال بنقرة واحدة.
3. **إنشاء الجداول وحساب الإدارة**: بناء كافة الجداول وحفظ الإعدادات وإنشاء حساب المشرف العام تلقائياً.
4. **حماية النظام**: إغلاق معالج التثبيت وإنشاء ملف الحماية `installed.lock`.

---

## 📁 هيكل الملفات في حزمة PHP:
```text
public_html/ (أو htdocs/)
│
├── index.php              (بوابة التشغيل الرئيسية بنظام CMS والتوجيه التلقائي)
├── install.php            (معالج التثبيت التلقائي مثل أنظمة CMS)
├── app.html               (واجهة التطبيق التفاعلية React SPA المترجمة)
├── .htaccess              (توجيه تلقائي لـ install.php عند أول زيارة وحماية الملفات)
├── config.php             (بيانات الاتصال بقاعدة بيانات MySQL - يتم توليده تلقائياً)
├── database.sql           (مخطط الجداول والبيانات لقاعدة البيانات)
│
├── api/
│   └── index.php          (خادم الـ REST API الكامل لجميع العمليات)
│
└── assets/                (ملفات التنسيق والبرمجة CSS / JS)
```

## 🚀 طريقة التثبيت في دقيقتين فقط:

### 1. تجهيز قاعدة البيانات في لوحة التحكم (cPanel أو الاستضافة المجانية):
- أنشئ قاعدة بيانات فارغة باسم من اختيارك (مثلاً: `school_db`).
- أنشئ مستخدماً لقاعدة البيانات وكلمة مرور، واربطه بقاعدة البيانات مع كامل الصلاحيات (**All Privileges**).

### 2. رفع الملفات إلى مجلد الموقع (`public_html`):
- ارفع محتويات حزمة PHP كاملة داخل مجلد `public_html` (أو `htdocs` في سيرفر XAMPP).

### 3. الدخول إلى موقعك في المتصفح:
- افتح رابط موقعك (مثال: `https://your-domain.com` أو `http://localhost/school`).
- سيتم نقلك تلقائياً إلى صفحة **معالج التثبيت التلقائي** (`install.php`).
- اكتب اسم قاعدة البيانات واسم المستخدم وكلمة المرور واضغط **"بدء التثبيت التلقائي"**.
- سيقوم المعالج بإنشاء جميع الجداول وملف `config.php` وحسابك في أقل من ثانيتين!

---

## 🔒 أمان النظام بعد التثبيت والتنظيف التلقائي الذاتي:
- بمجرد اكتمال التثبيت بنجاح، يقوم النظام تلقائياً بمسح ملف معالج التثبيت `install.php` ومسح `database.sql` لحماية بيانات وهيكل قاعدة البيانات من أي وصول خارجي.
- يتم نقلك وتوجيهك فوراً وتلقائياً إلى الصفحة الرئيسية للنظام وواجهة تسجيل الدخول.
- إذا كنت قد قمت بتثبيت قاعدة البيانات مسبقاً وما زال ملف `install.php` موجوداً، يمكنك الضغط على زر **"مسح ملف install.php والعودة للرئيسية"** أو حذفه من مدير الملفات، وسيتعرف النظام في `index.php` تلقائياً على أن المنظومة مثبتة ويعرض واجهة التطبيق فوراً.
